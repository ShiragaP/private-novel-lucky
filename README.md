## 📖 วิธีการเปิดอ่าน (Offline Reader)

1. **เปิดหน้าสารบัญ**:
   - ดับเบิลคลิกเปิดไฟล์ `ผมเป็นเจ้าของโรงพยาบาลจิตเวชพิศวง/index.html` บนเว็บบราวเซอร์ใดก็ได้ (Chrome, Edge, Firefox, Safari)
2. **เปิดอ่านตอนที่ 1 ทันที**:
   - ดับเบิลคลิกเปิดไฟล์ `ผมเป็นเจ้าของโรงพยาบาลจิตเวชพิศวง/chapters/chapter_0001.html`

### ฟังก์ชันพิเศษในหน้าอ่าน:
- **ไร้โฆษณา 100%**: ไม่มีแบนเนอร์ ป๊อปอัป หรือสคริปต์กวนใจ
- **Dropdown เลือกตอน**: มีเมนูดรอปดาวน์ทั้งด้านบนและด้านล่าง สามารถกดเลือกเปลี่ยนตอนได้ทันที
- **ปุ่มเปลี่ยนตอน**: `[⏮ ตอนก่อนหน้า]` และ `[ตอนถัดไป ⏭]`
- **คีย์ลัดบนคีย์บอร์ด**:
  - กดลูกศรซ้าย `←` เพื่อไปตอนก่อนหน้า
  - กดลูกศรขวา `→` เพื่อไปตอนถัดไป
- **ปรับขนาดตัวอักษร**: ปุ่ม `A-` และ `A+` (จำค่าที่ตั้งไว้ตลอดการอ่าน)
- **เปลี่ยนธีม**: ☀️ สว่าง (Light), 📜 ถนอมสายตา (Sepia), 🌙 มืด (Dark)

## 🚀 คำสั่งดาวน์โหลดตอนเพิ่มเติม

เปิดเทอร์มินัลในโฟลเดอร์ `ผมเป็นเจ้าของโรงพยาบาลจิตเวชพิศวง` แล้วรันคำสั่ง:

### 1. ดาวน์โหลดตอนช่วงที่ต้องการ (เช่น ตอนที่ 6 ถึง 20)
```bash
python clone_novel.py --start 6 --end 20
```

### 2. ดาวน์โหลดทุกตอนที่เหลือจนจบ (ทั้งหมด 1,630 ตอน)
```bash
python clone_novel.py --all
```
*(สคริปต์รองรับระบบ Resume อัตโนมัติ หากเน็ตหลุดหรือปิดไป เมื่อรันใหม่จะดาวน์โหลดต่อจากตอนที่ยังไม่มีทันที ไม่โหลดซ้ำ)*

### 3. อัปเดต/สร้างไฟล์ HTML ใหม่จากฐานข้อมูล
```bash
python clone_novel.py --regenerate-html
```
